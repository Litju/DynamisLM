# Security policy

Please do not publish credentials, private athlete data, unpublished research, or an exploitable vulnerability in a public issue.

Use GitHub's private vulnerability reporting or a private maintainer contact through the [Litju GitHub profile](https://github.com/Litju) to disclose security-sensitive findings. Include the affected commit, reproduction steps, impact, and a safe way to coordinate a fix. Reports should not include real athlete-identifying data when a synthetic reproduction is possible.

The project is research software and is not a clinical, diagnostic, rehabilitation, or return-to-play authority.
