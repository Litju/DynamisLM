# Scientific decision records

Research is pull-based. Add a decision record here only when an authorized implementation unit encounters a concrete scientific definition that is not already settled by the canonical architecture.

A decision record should state the exact question, sources inspected, population and method applicability, adopted decision, materially relevant alternatives, assumptions, limitations, method/registry version, and the implementation/tests that realize it. Do not use this directory for project-wide literature dumps or undocumented metric changes.
